## [1.0.0] - 2025-01-11

### Added

- Automatic product mockup generation from artwork images
- Multiple frame style options: black metal, white wood, gold ornate, natural oak, floating, and frameless
- Room scene backgrounds including living room, office, gallery, bedroom, and minimal
- Perspective transformation to match artwork angle to frame templates
- Realistic shadow compositing for professional appearance
- Frame overlay with proper lighting effects
- Multi-size export for different platforms: square (Instagram), 4:3 (eBay), 16:9 (hero), and thumbnail
- Batch processing for entire artwork folders
- Command-line interface for single images and batch operations
- Template-based mockup generation system
- Smart AI-powered compositing module
- PhotoRoom API integration for enhanced background removal
- Sample artwork and configuration files for demonstration
- Demo mode that works without API keys
- Visual showcase script for quick demonstration
- Comprehensive test suite
- CI workflow for automated testing
